# OPD 2 · ระบบจัดสรรกำลังบุคลากร

เว็บ static สำหรับใช้งานบน GitHub Pages

## วิธีใช้บน GitHub Pages

1. แตกไฟล์ ZIP แล้วอัปโหลดไฟล์ทั้งหมดเข้า repository โดยให้ `index.html` อยู่ที่ระดับรากของ repository
2. ไปที่ **Settings → Pages**
3. ใน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch ที่อัปโหลดไฟล์ และโฟลเดอร์ `/ (root)`
5. กด Save แล้วเปิด URL ของ GitHub Pages

ไฟล์ข้อมูลที่ผู้ใช้กรอกจะเก็บไว้ใน browser ของเครื่องนั้นผ่าน `localStorage` ไม่ได้ส่งขึ้น server
